# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to issues, pull requests, discussions and every other place where the project is represented.

In short: be respectful, assume good faith, keep criticism about the code, and do not harass anyone. Sexual language or imagery, personal attacks, and publishing private information about a person are not acceptable here.

## Reporting

If behavior in this project breaks that standard, report it to a maintainer in private. [.github/CODEOWNERS](.github/CODEOWNERS) lists the maintainers. Use the contact details on their GitHub profiles. If the report is about a maintainer, or you do not want to contact one, use the "Report content" link that GitHub shows on the comment or issue.

Maintainers keep reports confidential and reply within 5 working days.

## Enforcement

Maintainers can edit or remove comments, commits, issues and pull requests that break this code. They can block a contributor for a period or permanently. The enforcement guidelines of the Contributor Covenant (correction, warning, temporary ban, permanent ban) describe how maintainers choose a response.
